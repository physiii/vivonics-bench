# Würth 65100516121 Mini-B Part Note

Sources:
- Würth drawing mirrored by Farnell: `https://www.farnell.com/datasheets/1442461.pdf`
- Local KiCad footprint:
  `/usr/share/kicad/footprints/Connector_USB.pretty/USB_Mini-B_Wuerth_65100516121_Horizontal.kicad_mod`

Pin checklist:
- Pin 1 = VBUS.
- Pin 2 = D-.
- Pin 3 = D+.
- Pin 4 = ID.
- Pin 5 = GND.
- Shield pads tie to GND in the current board.

Current design:
- D-/D+ go through USBLC6 and 22 ohm series resistors to ESP32-S3 native USB.
- VBUS feeds USBLC6 pin 5 and D5 anode.
- ID is an intentional no-connect.

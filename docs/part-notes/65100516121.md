# Mini-B Connector Footprint / Procurement Note

Sources:
- Current schematic/BOM metadata: Würth `65100516121`, LCSC `C5120592`.
- Official Würth footprint/drawing source for the current PCB land pattern:
  `https://www.we-online.com/catalog/datasheet/65100516121.pdf`.
- LCSC order source for the active C-code:
  `https://www.lcsc.com/product-detail/USB-Connectors_Wurth-Elektronik-65100516121_C5120592.html`.
- The current PCB footprint is the KiCad Würth land pattern, matching the active
  orderable connector metadata.
- Local KiCad footprint:
  `/usr/share/kicad/footprints/Connector_USB.pretty/USB_Mini-B_Wuerth_65100516121_Horizontal.kicad_mod`

Pin checklist:
- Pin 1 = VBUS.
- Pin 2 = D-.
- Pin 3 = D+.
- Pin 4 = ID.
- Pin 5 = GND.
- Shield pads tie to GND in the current board.

Current design:
- J1 is the CP2102N USB-UART connector; D-/D+ go to the CP2102N through local
  discrete ESD clamps.
- J2 is the ESP32-S3 native USB connector; D-/D+ go to GPIO19/GPIO20 through
  local discrete ESD clamps.
- VBUS from each connector feeds a local 1N5819HW isolation diode into
  `VBUS_5V`, which then feeds the board +5 V OR-ing diode D5.
- CP2102N VBUS sense uses the copied-sheet 22.1 k / 47.5 k divider
  (`R55`/`R56`) plus `C45` bypass on `Net-(U10-VBUS)`.
- ID is an intentional no-connect.
- Shield pad 6 ties to board GND in the symbol and PCB.

Release status:
- Connector identity is resolved for the active board metadata: J1/J2 use
  Würth `65100516121` / LCSC `C5120592` on KiCad's Würth `65100516121`
  footprint. Final quote review, board-edge orientation, shield return, and USB
  ESD placement remain part of layout/procurement review.

Checker evidence:
- `check_usb_vbus_interface.py --policy topology` asserts J1/J2 pins 1-6,
  CP2102N QFN28 pins 4/5/8, ESP32-S3 native USB pins 13/14, discrete ESD
  clamps, 1N5819HW VBUS isolation, D5 +5 V OR-ing, CP2102N VBUS divider,
  UART, EN/BOOT, and ID no-connects.
- `check_usb_vbus_interface.py --policy connector-source-match` passes only when
  both J1/J2 use MPN `65100516121` and LCSC `C5120592` on the Würth footprint.
- PCB checker enforces connector/ESD/CP2102N/native-USB proximity and pad-net
  assignment.

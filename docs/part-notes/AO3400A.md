# AO3400A Part Note

Source:
- Alpha & Omega AO3400A datasheet:
  `https://www.aosmd.com/res/data_sheets/AO3400A.pdf`
  - The official AOS URL currently returns a bot/noindex HTML page to this
    shell environment, so release-time manual datasheet verification remains
    required.

Pin checklist:
- SOT-23 pin 1 = gate.
- Pin 2 = source.
- Pin 3 = drain.

Current design:
- Gate is driven from TLV9001 output through 1 kOhm.
- Source returns through a 10 ohm 2512 sense resistor.
- Drain connects to the laser cathode harness net `LASER_Nx`.
- The AO3400A is used as a linear low-side current-sink pass device here, not
  merely as a saturated switch. Its heat is `I * (LASER_V+ - Vf(laser) -
  I*10 ohm)`.

Layout notes:
- Treat drain/source/sense routing as current path, not ordinary small signal.
- Thermal/SOA must be checked against actual `LASER_V+`, selected laser diode
  forward voltage, duty cycle, and programmed current.

Checker evidence:
- Netlist checker asserts AO3400A pin functions and laser cathode/source/gate
  nets.
- PCB checker reviews laser-current route geometry and class membership.
- `check_laser_current_budget.py` checks the AO3400A dissipation for the selected
  diode forward-voltage and `LASER_V+` assumption.

# OPA380AID Part Note

Source:
- TI OPA380 datasheet: `https://www.ti.com/lit/ds/symlink/opa380.pdf`
- Local copy: `docs/datasheets/opa380.pdf`

Datasheet limits used in the design:
- Supply range is 2.7 V to 5.5 V; the bench design runs OPA380 from +5 V.
- Input common-mode range is up to `(V+) - 1.8 V`, so the bounded VBIAS
  network must stay below about 3.2 V on a 5 V rail.
- The first-order guarded linear output window used by the checker is
  0.10 V to 4.30 V on the 5 V rail. AD7606 +/-5 V input range is not the
  limiting range; OPA380 output headroom is.
- TI layout guidance says to minimize photodiode capacitance and stray
  capacitance at the summing junction and use guarding/leakage control.

Pin checklist:
- SOIC-8 pins 1, 5, and 8 are no-connects.
- Pin 2 is the inverting/summing input.
- Pin 3 is the non-inverting VBIAS input.
- Pin 4 is negative supply / board GND.
- Pin 6 is output.
- Pin 7 is positive supply / board +5 V.

Current design:
- Each SFH2201 anode goes to the local OPA380 pin 2 summing node.
- Feedback is a Bourns 3224W 2 M trimmer in parallel with 10 pF, with the
  wiper tied to the OPA380 output side.
- VBIAS is generated by a bounded 10 k trimmer network.
- `check_tia_readout_budget.py` asserts this topology and quantifies the
  bench readout range. At VBIAS = 1.5 V and RF = 2 MOhm the first-order
  OPA380 headroom is about +1.40 uA / -0.70 uA before the guarded output
  window clips; optical signal range is still a production calibration blocker.

Layout notes:
- The summing node must stay short, guarded, and away from switching/laser
  current traces.
- Local 100 nF decoupling is required at each OPA380 supply pin.

Checker evidence:
- Netlist checker asserts OPA380 pin functions, no-connect pins, TIA summing
  node contents, output node contents, and +5 V/GND rail membership.
- PCB checker enforces photodiode/input/feedback/decoupling/bias proximity.
- `check_tia_readout_budget.py` asserts TIA topology, VBIAS range against
  OPA380 common-mode range, OPA380 output headroom against AD7606 +/-5 V input
  range, and the expected-fail SFH2201 bright-ambient case.

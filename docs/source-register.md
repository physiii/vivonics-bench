## Open Source Conflicts / Missing Evidence

- The Mini-B orderable connector identity must be resolved before release. The
  copied MCU sheet metadata uses `920-462A2021S10101` / `C46391`, while the PCB
  land pattern is KiCad's Würth `65100516121` footprint. Electrical pins 1-6 are
  checked, but the orderable connector against the Würth land pattern still
  needs proof; mechanical fit and ordering source still need signoff.
- The current bench monitor-PD feedback circuit is not a universal 3-pin laser
  can interface. It is polarity-compatible with `D7805I`, `D6505I`, and
  `PLT5 520EB_P` in the 2026-06-28 Digikey cart, and the current `240R` /
  INA4180A1 gain-20 scaling covers the selected monitor-current range inside
  the local production ADC-headroom guard. D7805I 600 uA high-end monitor
  current maps to about 2.88 V. It still cannot read monitor telemetry
  from `PLT5 450GB` because that part has no monitor photodiode, so
  `MPD_RAW4`/`MPD4` is spare/open for the selected blue source.
- The SFH2201/OPA380 signal-PD topology is connected, but the TIA readout is a
  high-sensitivity bench range, not a proven production optical range. At
  VBIAS = 1.5 V and RF = 2 MOhm the OPA380 headroom is only about
  +1.40 uA / -0.70 uA; the SFH2201 1000 lx short-circuit-current example would
  require about 152 V of TIA swing. Define the real Vivonics optical
  photocurrent range, shielding, RF/VBIAS settings, and AD7606 calibration
  before production use.
- SS14 BOM row uses LCSC C2480. The schematic/PCB diode polarity is checked, but
  the exact C2480 manufacturer datasheet should be rechecked at order time.
- Commodity passive voltage ratings and steady-state resistor power are encoded
  in `check_passive_derating.py` for the bench design. Production still needs
  pulse/surge/current derating, lifecycle/AVL status, final orderable datasheets,
  and board-temperature evidence.
- The AP63205/AP63200 production component recommendation is not closed. The
  current bench schematic has less VIN ceramic and buck output capacitance than
  the Diodes reference guidance, so ripple/stability/transient measurements or a
  capacitor rework are required before production.
- IPC/J-STD class and final fabricator order tier are not selected. Current
  generated geometry is conservative, but board setup and release notes still
  need explicit manufacturing constraints.

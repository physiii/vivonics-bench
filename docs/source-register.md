## Open Source Conflicts / Missing Evidence

- The Mini-B orderable connector identity must be resolved before release. The
  copied MCU sheet metadata uses `920-462A2021S10101` / `C46391`, while the PCB
  land pattern is KiCad's Würth `65100516121` footprint. Electrical pins 1-6 are
  checked, but mechanical fit and ordering source still need signoff.
- The current bench monitor-PD feedback circuit is not a universal 3-pin laser
  can interface. It is polarity-compatible with `D7805I`, `D6505I`, and
  `PLT5 520EB_P` in the 2026-06-28 Digikey cart. It cannot read monitor
  telemetry from `PLT5 450GB` because that part has no monitor photodiode, so
  `MPD_RAW4`/`MPD4` is spare/open for the selected blue source.
- SS14 BOM row uses LCSC C2480. The schematic/PCB diode polarity is checked, but
  the exact C2480 manufacturer datasheet should be rechecked at order time.
- Commodity passive voltage ratings and steady-state resistor power are encoded
  in `check_passive_derating.py` for the bench design. Production still needs
  pulse/surge/current derating, lifecycle/AVL status, final orderable datasheets,
  and board-temperature evidence.
- IPC/J-STD class and final fabricator order tier are not selected. Current
  generated geometry is conservative, but board setup and release notes still
  need explicit manufacturing constraints.
